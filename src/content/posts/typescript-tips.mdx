## TypeScript를 더 잘 활용하는 방법

TypeScript를 사용하면서 발견한 유용한 팁들을 공유합니다.

### 1. Utility Types 적극 활용하기

TypeScript는 강력한 내장 유틸리티 타입들을 제공합니다:

```typescript
interface User {
  id: string;
  name: string;
  email: string;
  age: number;
}

// 일부만 선택
type UserPreview = Pick<User, 'id' | 'name'>;

// 일부 제외
type UserWithoutAge = Omit<User, 'age'>;

// 모두 선택적으로
type PartialUser = Partial<User>;

// 모두 필수로
type RequiredUser = Required<User>;
```

### 2. Type Guards로 안전하게

런타임에서 타입을 체크하는 Type Guard를 활용하세요:

```typescript
function isString(value: unknown): value is string {
  return typeof value === 'string';
}

function processValue(value: unknown) {
  if (isString(value)) {
    // 여기서 value는 string 타입으로 좁혀짐
    console.log(value.toUpperCase());
  }
}
```

### 3. Generic Constraints 활용

제네릭에 제약을 걸어 더 안전한 코드를 작성할 수 있습니다:

```typescript
interface HasId {
  id: string;
}

function findById<T extends HasId>(items: T[], id: string): T | undefined {
  return items.find(item => item.id === id);
}
```

### 4. Discriminated Unions

상태를 표현할 때 유용합니다:

```typescript
type LoadingState = {
  status: 'loading';
};

type SuccessState<T> = {
  status: 'success';
  data: T;
};

type ErrorState = {
  status: 'error';
  error: Error;
};

type AsyncState<T> = LoadingState | SuccessState<T> | ErrorState;

function handleState<T>(state: AsyncState<T>) {
  switch (state.status) {
    case 'loading':
      return 'Loading...';
    case 'success':
      return state.data; // data 접근 가능
    case 'error':
      return state.error.message; // error 접근 가능
  }
}
```

### 5. const assertions

객체나 배열을 불변으로 만들 때 사용합니다:

```typescript
const routes = [
  { path: '/', name: 'home' },
  { path: '/about', name: 'about' },
] as const;

// routes의 타입이 readonly로 고정됨
type Route = typeof routes[number]; // { path: string; name: string }
```
