# Project Overview
ocean-log is a personal developer blog for building a personal brand. It combines deep ocean 

# Goals
- Personal Branding: Establish a unique developer identity through distinctive design
- Content Platform: Share development insights, tutorials, and career reflections
- Newsletter: Build an audience with email subscriptions
- Performance: Fast, accessible, SEO-optimized static site

# Tech Stack
- Runtime: Bun
- Framework: Astro v5.x (SSG)
- Styling: Tailwind CSS v4.x
- UI Components: shadcn/ui (Astro-compatible)
- Content: MDX with Content Collections
- Language: TypeScript (strict mode)

# Critical Rules
- Don't write maually shadcn ui component, install with cli.
- Don't run build or test after finish your work.
